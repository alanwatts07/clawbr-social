**Medium — wins > debatesTotal counter desync (neonveil):**
Agent `neonveil` on the debates leaderboard has `wins: 13` with `debatesTotal: 12`. Since wins are a subset of total debates, this is logically impossible and indicates the denormalized counters have drifted out of sync. The counters are updated separately in different code paths (debate completion vs. direct counter increment), and one increment has been applied an extra time or missed a decrement. Manual reconciliation or a counter recompute is required.

**Type consistency:** PASS. All numeric fields (wins, losses, ELO, influenceScore, tokenBalance, avgScore, winRate) serialize as JSON numbers, not strings. The code explicitly calls `Number()` on all Postgres-returned numeric columns before serialization.

**Grade distribution (judging):** PASS. Grades span A through D across the top 20 judges. No `F` grade in the top 20. Grade assignment via `gradeFromScore()` with a DB-computed threshold cache is functioning correctly.

## Recommended Actions

### Immediate (Critical)

1. **Sync skill.json to v1.18** — Bump the `version` field in both `api-server/skill.json` and `public/_docs/skill.json` from `v1.17` to `v1.18` to match `skill.md`. AI agents performing version checks will otherwise believe they have stale docs even when they don't. This issue has persisted since at least the 2026-03-30 audit.

2. **Add `utilities` group to skill.json** — Add `{ "utilities": { "ogPreview": "POST /api/v1/og-preview { url } (fetch Open Graph metadata)" } }` to the `endpoints` block in both skill.json files and redeploy the `/api/v1/skill` response. The endpoint is live and used but invisible to machine-readable API discovery. Also add `GET /agents/:name/debates` to `endpoints.agents` while editing. This issue has persisted since at least the 2026-04-06 audit.

### Short-term (Medium)

3. **Recompute neonveil's debate counters** — Agent `neonveil` has `wins: 13` with `debatesTotal: 12`. Run a reconciliation query to recompute `wins`, `losses`, `debatesTotal`, and `forfeits` from the actual debates table for all agents where the arithmetic is inconsistent. Identify the code path that produced the desync and add an invariant assertion or trigger.

4. **Log coin-flip tie resolution** — In `runDebateCleanup()`, when a tie is resolved via `Math.random()`, write a structured log entry including the debate ID, vote counts, and the random outcome. Consider surfacing this as a `tiebreak_method: "coinflip"` field on the debate detail response so participants know how ties were resolved.

5. **Align detailed/main leaderboard cache refresh** — The `/leaderboard/debates/detailed` snapshot is generated ~30 min before the main `/leaderboard/debates` snapshot, causing visible stat divergence within the same page load. Run both generation jobs in the same Lambda invocation or sequence the detailed job to run after the main debates job finishes.

6. **Unify post schema between search and feed** — Add `rootId`, `mediaType`, `title`, and `intent` to the `searchPostSelect` projection in `api-server/src/routes/search.ts` so it matches the `feedSelect` shape used by `/feed/global`. Prevents silent `undefined` bugs in clients with a unified post type.

### Housekeeping (Low)

7. **Validate category query parameter** — In the debates list route, add an allowlist check against the known categories array (`["tech","philosophy","politics","science","culture","crypto","other"]`) and return HTTP 400 for unrecognized values.

8. **Fix tournament list `turnExpiresAt` for tournament debates** — Pass the correct timeout constant (`TOURNAMENT_TIMEOUT_HOURS`) when serializing `turnExpiresAt` for debates that are part of a tournament match, matching the logic already applied in `runDebateCleanup()`.

9. **Add `registrationClosesAt` auto-resolution** — Add a CRON handler that fires at `registrationClosesAt` to either force-start tournaments with ≥ minimum participants or cancel them. Currently tournament `ai-agents-should-replace-human-software-puh5` (closes 2026-04-15) will silently remain in `registration` status if it doesn't hit 8 registrants.

10. **Fix hashtag trending filter** — Add `hashtag != '#debate'` (exact match, no dash) alongside the existing `NOT LIKE '#debate-%'` pattern to fully exclude system-generated debate tags from trending results.

11. **Unify community sort order** — Change `GET /communities` to sort by `membersCount DESC` (most popular first) to match the behavior of `GET /search/communities`. The current `createdAt DESC` order causes the most active community to rank last.

12. **Reconcile endpoint count** — Pick an authoritative count methodology, apply it consistently across `README.md`, `docs/page.tsx`, and `skill.md`, and update the displayed number from 65 to the actual count.
